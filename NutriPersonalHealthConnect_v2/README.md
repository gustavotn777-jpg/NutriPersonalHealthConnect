# Nutricionista / Personal — Health Connect v2

Versão 0.2 do projeto Android.

Inclui:
- Health Connect 1.1.0 estável;
- permissões para exercícios, frequência cardíaca, passos, calorias, peso e distância;
- interface de conexão;
- estrutura para leitura por intervalo;
- arquitetura preparada para sincronização incremental por ChangeLogs.

A documentação oficial do Android recomenda `ReadRecordsRequest` para sessões de exercício e ChangeLogs para sincronização incremental.

Esta versão ainda é código-fonte, não APK.
